# KINGDOM — Technology & Solutions

Site institucional desenvolvido em HTML, CSS e JavaScript para apresentar a marca KINGDOM, seus valores, serviços e proposta de tecnologia aplicada à indústria.

## 🎯 Objetivo do Projeto

O projeto consiste em uma landing page institucional com foco em fortalecer a presença digital da empresa, transmitir credibilidade e destacar a atuação em automação, plataformas digitais, dados e soluções sob medida para o setor industrial.

## ✨ Funcionalidades

- **Homepage institucional** com apresentação da marca e proposta de valor
- **Seção de quem somos** para contar a história e a visão da empresa
- **Apresentação de soluções** com blocos de serviços e diferenciais
- **Navegação responsiva** para desktop e mobile
- **CTA e formulário de contato** para geração de leads
- **Layout moderno** com identidade visual escura e destaque em verde
- **Estrutura modular** em arquivos HTML, CSS e JavaScript

## 🚀 Tecnologias

- **HTML5**: estrutura e conteúdo da interface
- **CSS3**: estilização, responsividade e layout visual
- **JavaScript**: interações e comportamento da página
- **Font Awesome**: ícones de interface
- **Git**: versionamento do projeto
- **Servidor local**: execução via Python ou qualquer servidor estático
